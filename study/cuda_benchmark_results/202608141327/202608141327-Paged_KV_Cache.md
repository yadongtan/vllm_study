# Paged KV Cache 性能测试报告

## 1. 结论

本轮在 Packed CUDA Flash Attention V2 上接入了预热显存分析和预分配的
Paged KV Cache。1、4、8 并发均完成 128/128 请求，失败请求为 0，说明分页
缓存的跨 block 写入、历史读取以及请求结束后的 block 回收能够稳定工作。

当前版本尚未提升性能。相对原 Packed V2，输出吞吐分别下降 2.6%、5.9% 和
6.5%。原因是 Attention kernel 仍接收连续 packed K/V：每一层都需要通过
`index_select + reshape` 从物理 pages 整理完整历史 KV。它消除了缓存增长时的
`torch.cat`，但增加了一次同等规模的历史 KV gather，因此目前只是完成了固定
地址 KV 存储，尚未获得 vLLM Paged Attention 的零整理读取收益。

| 并发 | 原 Packed V2 (tok/s) | Paged KV (tok/s) | 吞吐变化 | vLLM (tok/s) | vLLM / Paged |
|---:|---:|---:|---:|---:|---:|
| 1 | 47.89 | 46.65 | -2.6% | 375.19 | 8.04x |
| 4 | 89.03 | 83.76 | -5.9% | 1305.21 | 15.58x |
| 8 | 105.55 | 98.66 | -6.5% | 2400.77 | 24.33x |

## 2. 测试口径

- 分支：`vllm_study/v2.0`，包含尚未提交的 Paged KV Cache 修改。
- GPU：NVIDIA GeForce RTX 4080 SUPER，16 GiB。
- 模型：`/opt/models/Qwen2-0.5B-Instruct`，BF16。
- Attention：`STUDY_USE_CUDA_FLASH_ATTENTION_V2=1`。
- `gpu_memory_utilization=0.8`。
- `max_num_seqs=32`。
- `max_batch_num_tokens=2048`。
- KV block size：16 token。
- 并发：1、4、8。
- 每档：128 请求。
- 每请求：固定 1000 token 输入、50 token 输出。
- 无限请求速率、忽略 EOS、温度 0。
- 原 Packed V2 对照：`cuda_benchmark_results/202608140213`。
- 原生 vLLM 对照：`cuda_benchmark_results/202608140242`。

## 3. 预热和 KV Cache 分配

服务启动后先执行一个 2048-token 假请求，丢弃全部 logits 和临时 KV，然后
根据预热峰值保留运行时激活显存，并把剩余预算分配给固定地址 KV blocks。

```text
总显存：15.99 GiB
gpu_memory_utilization 目标：12.79 GiB
2048-token 预热峰值：1.91 GiB
清理预热数据后的当前进程保留显存：1.00 GiB
为后续激活保留：0.91 GiB
KV Cache：10.89 GiB
KV blocks：59447
block size：16
理论总容量：951152 tokens
```

原 Packed V2 加载后平均显存约 2616 MiB；本轮加载后为 13316 MiB。增加的约
10.45 GiB 主要就是预分配 KV Cache。测试期间峰值只比加载后增加 114--360
MiB，说明请求执行期间没有重新扩张 KV 存储池，固定地址预分配目标已经实现。

## 6. 瓶颈与下一步

当前数据表明，单纯把 KV 存入 pages 不会自动获得 vLLM 性能。下一步必须让
CUDA Attention kernel 直接接收：

```text
固定地址 key_cache / value_cache
每个请求的 block_table
每个请求的 sequence length
本轮 token 的 slot_mapping
```

kernel 根据 `kv_position / block_size` 查找物理 block，直接从缓存池读取 K/V。
完成后可以删除每层的 `index_select`、`reshape` 和跨请求 `torch.cat`。随后再把
`block_table`、`seq_lens`、`slot_mapping` 做成固定尺寸 Tensor，才具备捕获
decode CUDA Graph 的完整条件。
