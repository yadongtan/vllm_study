# 202608150740 - Mixed 2D Layout

## 1. 迭代目标

将 mixed Prefill/Decode 的 hidden state 从 `[1, tokens, hidden]` 改为 vLLM 常用的
packed `[tokens, hidden]` 布局，减少三维路径的 view/stride 开销，并让线性层直接看到
packed token 矩阵。Prefill 和 Decode CUDA Graph 路径保持不变。

## 2. 实现

`Qwen2GraphModel.mixed()` 新增环境开关：

```bash
STUDY_USE_MIXED_2D_LAYOUT=1
```

开启后，mixed attention 只将 Q/K/V 组织成 attention 所需的三维 head 形状，o_proj、
RMSNorm、MLP 和 SwiGLU 全部使用二维 packed token 张量。默认值为 `0`。

## 3. 测试口径

- Qwen2-0.5B-Instruct，BF16；
- 每请求 1000 input、50 output，128 requests；
- 16/32 并发，`request-rate=inf`，`ignore-eos`；
- `max_model_len=2048`、`max_num_batched_tokens=2048`、`max_num_seqs=32`；
- 使用当前最佳 mixed fused RoPE、vLLM FlashAttention、vLLM fused ops；
- 吞吐按真实 `6400 / duration` 计算。

## 4. 结果

| 版本 | 16 并发 tok/s | 32 并发 tok/s |
|---|---:|---:|
| 同机基线（`202608150720`，2D 关闭） | 2281.44 | 2777.02 |
| Mixed 2D layout | 2300.48 | 2752.98 |
| 相对变化 | **+0.83%** | **-0.87%** |

独立 profiler 的 3 步 mixed forward CUDA 时间从约 70.47 ms 降至约 69.75 ms，约 1.0%，
但该收益不足以稳定转化为端到端吞吐，32 并发还出现轻微回退。

## 5. 资源数据

## 6. 结论

2D layout 的 profiler 方向正确，但当前收益太小且高并发没有稳定改善，因此不改为默认。
后续若实现 vLLM 风格的 piecewise compiled runner，可继续复用这一布局；单独作为一项
优化暂不纳入当前最佳配置。
