# v2 CUDA 性能测试报告（WSL Ubuntu 24.04）

## 结论

本次测试在 WSL Ubuntu 24.04、CUDA GPU 上完成。修复请求结束后 KV Cache 未释放的问题后，自定义实现的 1/4/8 并发均完成全部 128 个请求且无失败。随着并发增加，吞吐从 1,050.8 token/s 提升到 1,757.6 token/s；并发 8 时 GPU 平均利用率 56.6%，峰值 99%，显存平均占用 7,835 MiB、峰值 8,350 MiB。

## 测试口径

- 并发：1、4、8
- 每档请求数：128
- 每个请求：1,000 输入 token、50 输出 token
- 数据集：random，`random-range-ratio=0`
- `request-rate=inf`、`ignore_eos=true`、`temperature=0`
- 自定义调度参数：`max_num_seqs=32`、`max_num_batched_tokens=2048`、`chunk_prefill_tokens=2048`
- 模型：Qwen2-0.5B-Instruct，`bfloat16`

## KV Cache 修复

请求完成时从 `kv_cache_manager` 移除对应 request id：

```python
if running_req.finished:
    self.kv_cache_manager.pop(running_req.req_id, None)
    self.finished_list.append(running_req)
```

这样已完成请求的 key/value 张量不会继续占用显存，也不会影响后续请求。
